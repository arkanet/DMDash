Quick start

1. Install DarkMesh iOS

Use AltServer and AltStore to install the signed .ipa on your iPhone.

DarkMesh iOS installer
2. Connect a node

Use native iOS BLE from the app, Bluefy/Web Bluetooth from the web client, or Network TCP/HTTP(S) only when DMDash is served from the same LAN as the bridge or gateway.

/connections
3. Use the dashboard

Once a device is connected, move between Dashboard, Messages, Map, Settings, and Nodes from the sidebar.

4. Keep the runtime active

In the browser, scheduled sends, distress beacons, hunt forwarding, and live notification loops work while the tab stays open and connected.

Important: Bluetooth and Serial require browser support. HTTP(S) and Network TCP bridge/gateway connections require DMDash to run from a local LAN server, not from an external domain.

Web client with Bluefy

The DMDash web client can also run from iPhone through Bluefy. Bluefy acts as a Web Bluetooth wrapper, opens the iOS Bluetooth picker, and lets the site talk directly to the node.

1. Open Bluefy Allow Bluetooth and notifications, then open the current DMDash Vercel URL.
2. Go full screen Use the Bluefy menu to enter full screen mode when you want an app-like surface.
3. Pair from DMDash Open Add Connection, choose Bluetooth, select the device, and allow future background connections.
No Meshtastic app required The older video used the official Meshtastic app only for first pairing; the updated flow starts pairing from the iOS Bluetooth picker.
