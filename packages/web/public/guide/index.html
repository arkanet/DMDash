Quick start

1. Connect a node

Use the Connections page to add an HTTP(S), Bluetooth, or Serial transport.

/connections
2. Open the main app

Once a device is connected, move between Dashboard, Messages, Map, Settings, and Nodes from the sidebar.

3. Keep the tab open for automations

Scheduled sends, distress beacons, hunt forwarding, and live notification loops work while the browser tab stays open and connected.

Important: Bluetooth and Serial require browser support. HTTP(S) connections can require you to accept a self-signed certificate first.

What the current build already covers

Dashboard Notifications, traceroute history, scheduled message rules, distress beacon, hunt forwarding, import/export, pruning.
Messages Broadcast and direct chats, replies, mentions, reactions, emoji picker, compression hints, inline node status.
Map and nodes Live markers, node popups, details dialog, status badges, environment metrics, neighbor info, filters, favorites.
Settings and Remote Admin Radio, device, and module configuration locally and remotely, with firmware-aware tab availability.
